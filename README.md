# Multi-Coin-Trading-Signals-Desktop-App
Windows app for beginners that upgrades BTC-only prototype to multi-coin (BTC, ETH, SOL, BNB, XRP+). Uses live exchange APIs to calculate EMA, RSI, MACD, ATR and generate explained BUY/SELL/NEUTRAL signals with 0-100 strength. Includes charts, watchlist, alerts, journal, backtesting and CSV/PDF export. Educational, read-only, no auto-trading.
